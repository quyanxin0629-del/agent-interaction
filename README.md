# 多 Agent 协作台

在一台 Mac 上，提交一次任务，再从已登录的桌面 Agent 中指定谁处理、谁评审。协作台通过两款软件现有的图形界面交接草稿、评审意见和修订稿，在明确通过后展示最终结果。

## 打开应用

在 Finder 打开项目中的 `dist` 文件夹，双击 `AgentInteraction.app`。系统要求为 macOS 14 或更高版本。项目用 SwiftUI 构建界面，以 Swift 执行本机任务编排，并通过 macOS 辅助功能访问桌面界面。

## 使用

1. 打开已登录的目标软件和要使用的会话。使用自动交接时，按协作台提示在系统设置中授权辅助功能。
2. 输入任务，为「处理」和「评审」各选一个桌面客户端及会话，确认后启动。
3. 处理方生成草稿，评审方根据原始任务给出明确的通过或返修结论。收到返修意见后，协作台把意见送回处理方，再将修订稿送审。每项任务最多自动修订两次，共可评审三次。
4. 明确通过时，页面展示获批稿件。若达到返修上限，或评审回复无法识别为有效结论，流程结束并保留草稿和评审记录，供你查看原因。

需要手动交接时，按提示将待发内容复制到选定的原客户端会话，待回复完成后将本轮完整回复粘贴回协作台。若页面显示已尝试发送，请先核对原会话中的消息，再决定如何继续。你可以随时停止后续交接，正在运行的客户端任务可在原窗口处理。

## 兼容性

自动交接依赖目标软件向 macOS 提供的界面信息，包括会话标识、输入框、发送按钮和回复状态。本机 Codex 和 Gemini 的完整自动收发尚待实测。可先使用手动交接完成流程。若收到登录或审批提示，请在原窗口完成操作。

任务记录保存在本机。目标软件按自身的账号和处理方式接收任务内容。

## 开发构建

开发者可用项目内的 `scripts/build-app.sh` 重新生成应用包。测试使用 Swift Testing。本机 Swift 6.4 的命令行开发工具需要通过 `-Xswiftc -load-plugin-library` 显式加载工具链中 `usr/lib/swift/host/plugins/testing/libTestingMacros.dylib`。打包使用临时签名。重新构建后若系统提示需要权限，可在 macOS 的隐私与安全设置中授权当前应用。
